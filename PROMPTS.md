## Примеры запросов

* Проверить pytest-тесты на независимость и корректность assertions.
* Помощь при рефакторинге отдельных pytest-тестов;
* Помочь настроить Allure для pytest.
* Проверить конфигурацию Ruff для Python-проекта.
* Провести ревью структуры проекта и документации.

Фактические результаты тестирования и поведение API определялись путем выполнения запросов к тестовому сервису.
