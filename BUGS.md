# Bugs

## BUG-001 — API позволяет создать объявление с отрицательной ценой

**Серьёзность:** Major

**Окружение:**

* API: `https://qa-internship.avito.com`
* Метод: `POST /api/1/item`
* ОС: macOS
* Python: 3.14
* Тестирование: pytest + requests

**Шаги воспроизведения:**

1. Зарегистрировать пользователя.
2. Авторизоваться и получить Bearer-токен.
3. Отправить POST-запрос на `/api/1/item` с валидным `sellerID` и `price=-1`.
4. Передать остальные обязательные поля с корректными значениями.

**Фактический результат:**
API возвращает HTTP `200`, и объявление с отрицательной ценой успешно создаётся.

**Ожидаемый результат:**
API должен отклонить запрос с HTTP `400`. Объявление с отрицательной ценой не должно создаваться.

**Связанный автотест:** `test_create_item_with_negative_price`

**Окружение:**

* API: `https://qa-internship.avito.com`

* Python: 3.14
* Тестирование: pytest + requests

**Шаги воспроизведения:**

1. Зарегистрировать пользователя.
2. Авторизоваться и получить Bearer-токен.
3. Отправить POST-запрос на `/api/1/item`.
